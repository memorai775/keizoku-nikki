# 継続日記

毎日の習慣（勉強、筋トレ、日記など）を、カレンダーにワンタップで記録するWebアプリです。

- 日付をタップして「達成」、もう一度タップで取り消し
- 現在の連続日数・最長連続日数・今月の達成率を表示
- 習慣を複数登録して、色分け・タブで切り替え
- ダークモード対応、ホーム画面に追加してオフラインでも使えます

## データについて

記録はすべて、使っている端末のブラウザ内（localStorage）に保存されます。サーバーには送信されません。
機種変更するときは、設定の「エクスポート」で保存したJSONファイルを、新しい端末で「インポート」してください。

ブラウザの履歴・サイトデータを消去すると記録も消えるので、ときどきエクスポートしておくと安心です。

## 開発者向け

- ビルド不要。`index.html` 1ファイルにHTML・CSS・JavaScriptがまとまっています
- `index.html?test` で開くと、日付計算（月またぎ・うるう年など）の自己テスト結果を表示します
- 更新を公開したら `sw.js` の `VERSION` を上げてください（古いキャッシュが削除されます）
